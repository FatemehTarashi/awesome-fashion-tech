# 3D Design & Simulation

- [CLO3D](https://www.clo3d.com/) 🆓 🎓 💰  
  نرم‌افزار حرفه‌ای طراحی سه‌بعدی لباس و شبیه‌سازی پارچه.

- [Marvelous Designer](https://www.marvelousdesigner.com/) 💰  
  ابزار محبوب شبیه‌سازی لباس برای Fashion، Game و CGI.

- [Browzwear](https://browzwear.com/) 💰  
  پلتفرم طراحی دیجیتال پوشاک برای صنعت مد.

- [Style3D](https://www.style3d.com/) 💰  
  پلتفرم 3D Garment Design و شبیه‌سازی Real-time.

- [Blender](https://www.blender.org/) 🆓 🟢  
  نرم‌افزار متن‌باز سه‌بعدی با قابلیت شبیه‌سازی پارچه و Fashion Rendering.

# Pattern Making & CAD

- [Optitex](https://optitex.com/) 💰  
  نرم‌افزار CAD و Pattern Making برای صنعت پوشاک.

- [TUKAcad](https://tukatech.com/) 💰  
  سیستم طراحی الگو و grading دیجیتال.

- [Seamly2D](https://github.com/fashionfreedom/seamly2d) 🆓 🟢  
  ابزار متن‌باز طراحی الگو و Pattern Drafting.

- [Valentina](https://valentinaproject.bitbucket.io/) 🆓 🟢  
  نرم‌افزار متن‌باز طراحی الگو بر پایه اندازه‌گیری‌های پارامتریک.
